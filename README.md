# Hoard

This is a repo where I hoard tutorials, research, and other projects carried out by an LLM. Each directory represents a distinct project I had claude or GPT put together. 

Back in the day when I wanted to learn a new technology, I would find a tutorial. They were great, but always very generic, and I would have to do extra work to apply the tech to my project. Now I just have the agent generate a tutorial with the exact context my situation demands.
